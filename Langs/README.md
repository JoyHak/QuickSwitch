The [reference](English.md) includes headings, quotes with explanatory text, and *[explanations]* to help you better understand the context of a specific option, setting, or tooltip:

```markdown
##### Menu
>  Menu display behavior; menu options behavior

Show menu after: *[menu display behavior]*
- Disabling Auto Switch *[after diasbling Automatic Path Switching menu option]*
```

---

The final localization file (in a free form) should contain only the headings and the translated text:

```markdown
##### Menu
Show menu after:
Disabling Auto Switch
```
